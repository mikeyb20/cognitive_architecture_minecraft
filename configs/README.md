# Configs

- `archetypes/`: explorer, builder, guardian, helper (#44). Parameter means from spec §19, drawn per agent from Normal(mean, 10%). Proposals until the sim pilot.
- `scenarios/`: first night, commanded tasks, open day, harsh episode, lava bridge, long horizon, incubation, far food, dusk errand, hostile at the food, expedition, held-out terrain, triadic shock bouts (spec §21, §20.1, §27 step 15; benchmark B3).
- `experiments/`: arms × scenarios × seeds × LLM tier (spec §24, §26). `floor` (default true) turns on the shared survival floor of plan §5.0: the player asks for a shelter at each dusk, for every arm. Each arm's `teacher` (default true) is the shared teacher of 01 §4.11: when the player asks for a shelter, the brain is shown the recipe, and arms A and B see its next step marked as commanded; `teacher = false` is the teacher-off rerun (plan §5.0), for any arm. `teacher_off = true` adds that rerun after every arm that has the teacher. `teach_days = N` has the teacher show recipes only on the first N days (the test is still explained), for the teachability score.
