# Docs

The theory documents (the framework paper draft, the definitions, the agent plan and the build spec) are kept outside this repository and are not published here. They remain the design authority for the architecture.

The code cites them by section: `spec §N` (build spec), `01 §N` (definitions), `00 §N` (paper draft), and `#N` (the project's decisions log). Public-facing explanations of the architecture will be added here as the code settles.
